freeCodeCamp: Back-End Development & APIs

Welcome to my repository for the freeCodeCamp Back-End Development & APIs certification projects.

This repository tracks my journey learning Node.js and backend development. Rather than just doing basic course tasks, I use another approach for each project to ensure both mastery of course material and practical application.

Project Structure:

Each project folder in this repository contains two core versions:

prv.js: The original baseline script written directly within the freeCodeCamp workspace to satisfy the core certification requirements.

[project-name].js: A general-purpose, refactored version enhanced with custom features, error handling, input validation.

Running the Code

To run any of the general-purpose tools locally:

Clone the repository:

git clone https://github.com/ItsMounirDz/Backend-Course.git
cd Backend-Course


Run a specific utility:

node <folder-name>/<script-name>.js [arguments]
